# 本地宝可梦图鉴 · 安装包下载

中文宝可梦图鉴，在自己电脑上运行，用浏览器打开，不需要联网。仅供个人非商业使用。

## 下载

到 [Releases → latest](https://github.com/edenz99-L/pokedex-local-releases/releases/latest) 下载对应系统的安装包：

| 系统 | 文件 |
| --- | --- |
| Windows | `pokedex-local-windows.zip` |
| Mac | `pokedex-local-mac.dmg` |
| Linux | `pokedex-local-linux.tar.gz` |

## 使用

- **Windows**：解压后双击「启动图鉴.bat」。想用手机访问就双击「启动图鉴（允许手机访问）.bat」。
- **Mac**：打开 dmg，把「本地宝可梦图鉴」拖到「应用程序」，然后打开它。第一次打开如果被拦，到「系统设置 → 隐私与安全性」里点「仍要打开」。
- **Linux**：解压后运行 `./启动图鉴.sh`。

每个安装包里都有一份「使用说明.txt」。

## 更新

图鉴打开时会自动检查这里的 `latest.json`，有新版本时页面顶部会出现提示。更新方法：下载新版，关掉旧版，用新版替换旧版即可。
收藏、队伍和导入的地图保存在系统的用户目录里，替换程序不会丢失。
